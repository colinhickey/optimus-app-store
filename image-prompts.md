# Image Prompts: Original Apps

Complete, copy-paste prompts to regenerate the original 15 app images in the same style as the new set, plus the two new apps still waiting for artwork.

**How to use:**
- Every prompt already includes the shared robot description and style, so paste each one as-is.
- Save each image with the filename shown. Any format is fine (.jpg, .jpeg or .png); tell me when they're in `images/` and I'll convert them and update `data.json`.
- **Dog** is already done (`dog-pet.jpg`), so it isn't included here.
- Prompts avoid naming real people. If a generator still blocks one, soften it: drop costume details or props that could read as a specific person, violence or a uniform.
